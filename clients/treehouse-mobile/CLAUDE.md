# Treehouse Mobile: agent notes

Read [`AGENTS.md`](AGENTS.md) in this directory and the design set in
[`docs/treehouse-mobile/`](../../docs/treehouse-mobile/README.md) before changing anything here.

The rule most often missed: every commit that touches this directory or `docs/treehouse-mobile/`
must update `docs/treehouse-mobile/PROGRESS.md` in the same commit. From the repo root, run
`scripts/check_treehouse_mobile_progress.sh` before committing.
