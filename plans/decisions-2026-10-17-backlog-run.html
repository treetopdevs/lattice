D-01Slice sessions run on Opus 5.5; the coordinator stays on Fable

When
2026-10-17, before slice 1
Context
Usage at start: 5-hour window 58% (resets in 49 min), weekly all-models 83%, weekly Fable 96% (both weekly windows reset in 3 d 14 h). The user asked to run to 100% and reset.
Decision
Start every slice session with model: opus so implementation work spends the all-models window rather than the 4% of Fable headroom. Coordination, verification and this record stay on Fable. Codex Sol 6.1 xhigh reviews are outside this budget and are used at every PR.
Why
A Fable weekly lockout lasts three and a half days; an Opus slice plus a Codex adversarial review keeps the PR quality bar while getting more backlog through before any reset.
Reversal
If the user resets the weekly windows, later slices may inherit Fable again.

Context
